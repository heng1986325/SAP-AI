## 3. 出参结构 (O_RESP-RESP)

### 3.1 统一字段（固定，无需修改）

| 外围系统字段 | SAP 字段 | 数据元素 | 名称 | 字段类型 | 字段长度 | 说明 |
|-------------|----------|----------|------|----------|----------|------|
| MSGTY | MSGTY | `msgty` | 消息类型 | CHAR | 1 | S: 成功，E: 失败 |
| MSGTX | MSGTX | `bapi_msg` | 消息文本 | CHAR | 220 | |
| MSGID | MSGID | `msgid` | 消息识别 | CHAR | 20 | |
| MSGNO | MSGNO | `msgno` | 系统消息编号 | CHAR | 3 | |
| UUID | UUID | `zesysuuid_c32` | 唯一ID | CHAR | 32 | 与请求UUID一致 |
| SAPNUM | SAPNUM | `zesapn` | SAP号码 | CHAR | 20 | 预留 |
| **RESP** | **RESP** | 内表 | 库存明细数据 | — | — | **字段名固定为 RESP** |

### 3.2 明细行 (O_RESP-RESP)

| 外围系统字段 | SAP 字段 | **数据元素** | 名称 | 字段类型 | 字段长度 | 小数位 | 来源表 | 备注 |
|-------------|----------|-------------|------|----------|----------|--------|--------|------|
| | | | | | | | | |

> **字段类型与数据元素的对应关系**：
> - `CHAR` → 数据元素如 `matnr`、`charg`、`werks_d`、`lgort_d`
> - `QUAN` → 数据元素如 `labst`（**必须**标注 `@Semantics.quantity.unitOfMeasure`，见下方注解）
> - `UNIT` → 数据元素如 `meins`
> - 自定义字段（无标准元素）→ 直接用 `abap.char(N)` 或 `abap.dec(N,M)`

## 4. DDIC 创建清单

### 4.1 创建顺序

```
1. 行结构 → ZS{编号}_OUT
2. 表类型 → ZTT{编号}_OUT
3. RES 结构 → ZS{编号}_RESP（统一字段 + RESP 内表）
4. 函数模块 → ZFM_{编号}
```

### 4.2 QUAN 类型字段必填注解

**出参行结构中如有 QUAN 类型字段（数量、金额等），必须标注 `@Semantics.quantity.unitOfMeasure`。**

```abap
"格式：全小写 '结构名.单位字段名'
@Semantics.quantity.unitOfMeasure : 'zs{编号}_out.meins'
labst  : labst;   "QUAN 类型，引用标准数据元素 labst
meins  : meins;   "UNIT 类型，引用标准数据元素 meins
```

> **注意**：注解值必须是全小写 `结构名.字段名`，大写会报错。被引用的单位字段必须在同一结构中。

## 5. 开发前校验清单

以下条目在开始编码前与需求方确认，可避免大量返工。

| # | 检查项 | 说明 |
|---|--------|------|
| 1 | **出参行表字段名** | 固定为 `RESP`，不得使用 `RES`、`DATA` 等其他名称 |
| 2 | **入参业务参数字段名** | 固定为 `REQ`，嵌套在 `I_REQ-REQ` 下 |
| 3 | **每个字段的数据元素** | 标注标准数据元素名（如 `matnr`、`labst`），不要只写类型和长度 |
| 4 | **QUAN 字段的单位** | 标注对应的单位字段名，用于 `@Semantics.quantity.unitOfMeasure` 注解 |
| 5 | **返回类型** | 单条记录用 `ZSREST_OUT`，多条记录（表格）用专用 `_RESP` 结构 |
| 6 | **函数模块命名** | 与接口编号一致，遵循 `ZFM_{模块}I{序号}` 格式 |
| 7 | **必填参数** | 明确标注哪些参数为必填，函数开头需校验 |
| 8 | **可选过滤** | 明确哪些参数为可选过滤（有值精确匹配，为空不筛选） |
